# DESARA

## Desa Surat dan Administrasi

Frontend aplikasi DESARA untuk digitalisasi layanan surat administrasi Desa Milangasri.

### Struktur
- `index.html` — halaman utama aplikasi
- `css/style.css` — stylesheet dan tampilan
- `js/app.js` — logika aplikasi
- `images/` — aset logo dan gambar

Buka `index.html` untuk menjalankan aplikasi.
